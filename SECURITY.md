# Security

harnessbox is an isolation layer, so a way out of a box, into another user's home or login, past the egress allowlist, or into the
runner or the service matters most. The README's threat model lists the boundaries it does not claim.

Report a vulnerability privately through this repository's **Security** tab ("Report a vulnerability"), not in a public issue. Include
the harnessbox version, the host (kernel, bubblewrap, Docker if any) and the steps. Fixes go into the latest release only.
